# ডকার-ফার্স্ট ডেভেলপমেন্ট নীতি (Docker-First Development Rule)

## ১. মূল নীতি (Zero Host Pollution Mandate)
ডেভেলপমেন্টের সময় ইউজারের লোকাল পিসির কোনো রানটাইম বা রিসোর্স (যেমন: লোকাল পোস্টগ্রেসকিউএল সার্ভিস, লোকাল জাভা/জেডিকে পাথ বা গ্লোবাল নোড প্যাকেজ) ব্যবহার বা পলিউশন করা সম্পূর্ণ নিষিদ্ধ।

> 🐳 **কোর ম্যান্ডেট**:  
> ডেটাবেজ, ব্যাকএন্ড স্প্রিং বুট সার্ভিস এবং ফ্রন্টএন্ড রিঅ্যাক্ট অ্যাপ—সবকিছু **ডকার কন্টেইনারের (Docker Containers)** ভেতরে আইসোলেটেড অবস্থায় চলবে। লোকাল পিসিতে শুধু কোড এডিটিং হবে, আর ডকার ভলিউম মাউন্টের মাধ্যমে কন্টেইনারে স্বয়ংক্রিয়ভাবে লাইভ হট-রিলোড হবে।

## ২. ডকার কনটেইনার আর্কিটেকচার

```
+--------------------------------------------------------------+
|                   DOCKER COMPOSE NETWORK                     |
|                                                              |
|   +-------------------+  +-------------------+               |
|   |   Frontend App    |  |    Backend App    |               |
|   |  (React 19, Vite) |  |   (Java 21, Spring|               |
|   |    Port: 5173     |  |     Port: 8080    |               |
|   +---------+---------+  +---------+---------+               |
|             |                      |                         |
|             +----------+-----------+                         |
|                        |                                     |
|                        v                                     |
|              +-------------------+                           |
|              |  PostgreSQL 16/17 |                           |
|              |    Port: 5432     |                           |
|              +-------------------+                           |
+--------------------------------------------------------------+
```

### সার্ভিসের রূপরেখা:
1. **`postgres` (Database Container)**:
   - ইমেজ: `postgres:16-alpine`
   - ডেটা পারসিস্টেন্স: Docker Named Volume (`postgres_data`) ব্যবহার হবে, যাতে কন্টেইনার রিস্টার্ট হলেও ফ্যাক্টরি ডেটা না হারায়।
2. **`backend` (Java 21 Spring Boot Container)**:
   - ইমেজ: `eclipse-temurin:21-jdk-alpine`
   - লোকাল কোডের সাথে ভলিউম মাউন্ট (`./backend:/app`) থাকবে।
   - স্প্রিং ডেভটুলস (Spring DevTools) দিয়ে জাভা কোড সেভ করলেই কন্টেইনারে লাইভ রিলোড হবে।
3. **`frontend` (React 19 Vite Container)**:
   - ইমেজ: `node:22-alpine`
   - লোকাল কোডের সাথে ভলিউম মাউন্ট (`./frontend:/app`) থাকবে।
   - Vite HMR (Hot Module Replacement) দিয়ে ব্রাউজারে ইনস্ট্যান্ট রিফ্রেশ হবে।
4. **`pgadmin` (Database Management UI - Optional)**:
   - পোর্ট ৫০৫০ দিয়ে ব্রাউজারে সরাসরি পোস্টগ্রেসকিউএল ডেটাবেজের টেবিল দেখা যাবে।

## ৩. কমান্ড ও এক্সিকিউশন রুলস
- কোনো কিছু রান বা টেস্ট করতে হলে ডকারের ভেতর দিয়ে করতে হবে:
  - ব্যাকএন্ড টেস্ট রান: `docker compose exec backend ./mvnw test`
  - ফ্রন্টএন্ড বিল্ড টেস্ট: `docker compose exec frontend npm run build`
  - পুরো সিস্টেম চালু: `docker compose -f docker/docker-compose.yml up -d`
  - পুরো সিস্টেম বন্ধ: `docker compose -f docker/docker-compose.yml down`
