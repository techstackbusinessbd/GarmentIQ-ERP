# ডেটাবেজ স্কিমা ও কলাম নেম পূর্বানুমোদন নীতি (Database Schema & Column Approval Gate)

> 🛑 **অলঙ্ঘনীয় ডেটাবেজ আইন**:  
> ডেটাবেজে কোনো নতুন টেবিল তৈরি বা বিদ্যমান টেবিলে নতুন কলাম যুক্ত করার আগে প্রতিটি কলামের নাম, ডেটা টাইপ এবং কনস্ট্রেইন্ট আমাদের **Product Director / CTO (স্যার / বস)**-কে দেখিয়ে রিভিউ ও অনুমোদন করিয়ে নেওয়া বাধ্যতামূলক।

## ১. অনুমোদনের জন্য কলাম উপস্থাপনার ফরম্যাট (Mandatory Review Template)

আরিফুল ইসলাম (Tech Lead) এবং তানভীর আহমেদ (Architect) কোনো টেবিল তৈরির প্রস্তাব দেওয়ার সময় নিচের স্ট্যান্ডার্ড ছকে কলামের তালিকা পেশ করবেন:

### ছকের নমুনা:
| কলামের নাম (snake_case) | ডেটা টাইপ (PostgreSQL) | Nullable? | ডিফল্ট ভ্যালু | কনস্ট্রেইন্ট / রিলেশন | ব্যবসায়িক উদ্দেশ্য / ব্যাখ্যা |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id` | UUID | NOT NULL | - (App UUIDv7) | PRIMARY KEY | RFC 9562 টাইম-অর্ডারড ইউনিক আইডি (সাধারণ ID নিষিদ্ধ) |
| `style_code` | VARCHAR(50) | NOT NULL | - | UNIQUE | বায়ারের নিজস্ব স্টাইল নম্বর |
| `unit_price` | NUMERIC(12, 4) | NOT NULL | 0.0000 | CHECK (`unit_price` >= 0) | প্রতি পিসের FOB মূল্য |
| `status` | VARCHAR(30) | NOT NULL | 'DRAFT' | - | অর্ডারের বর্তমান অবস্থা |
| `created_at` | TIMESTAMPTZ | NOT NULL | CURRENT_TIMESTAMP | - | রেকর্ড তৈরির সময় |

> ⚠️ **প্রাইমারি কি বাধ্যবাধকতা**: প্রতিটি টেবিলের প্রাইমারি কি অবশ্যই `UUID` হতে হবে এবং মান বাধ্যতামূলকভাবে **UUIDv7**। কোনো অটো-ইনক্রিমেন্ট ইন্টিজার (`INT`, `BIGINT`) বা সাধারণ র‍্যান্ডম `UUIDv4` ব্যবহার সম্পূর্ণ নিষিদ্ধ।

## ২. রিভিউ প্রক্রিয়া ও ওয়ার্কফ্লো (Review & Execution Workflow)

```
[আরিফ: টেবিল ও কলাম তালিকা ড্রাফট] ➔ 🛑 [স্যার / সিটিও কলাম রিভিউ ও অ্যাপ্রুভাল] ➔ [আরিফ: Flyway SQL মাইগ্রেশন ও JPA Entity তৈরি]
```

1. **প্রস্তাবনা পেশ**:  
   ফিচারের রিকোয়ারমেন্ট অনুমোদনের পর, আরিফ ডেটাবেজের প্রতিটি টেবিলের জন্য প্রস্তাবিত কলামগুলোর তালিকা বাংলায় সহজ ব্যাখ্যাসহ চ্যাটে বসের সামনে পেশ করবেন।
2. **বসের রিভিউ ও ফিডব্যাক**:  
   - বস কলামের নাম পরিবর্তন, সংযোজন বা বিয়োজন করতে পারেন।
   - বস অনুমোদন দিলে বলবেন: *"কলামের নাম ঠিক আছে, মাইগ্রেশন লেখো"* বা *"Approved"*.
3. **কঠোর নিষেধাজ্ঞা (Strict Prohibition)**:  
   - বসের সম্মতি পাওয়ার আগে কোনো Flyway SQL ফাইল (`V1__...sql`) তৈরি করা যাবে না।
   - স্প্রিং বুটের কোনো JPA Entity ক্লাসে টেবিল বা ফিল্ড ডিফাইন করা যাবে না।
   - ডেটাবেজে কোনো DDL স্টেটমেন্ট (`CREATE TABLE`, `ALTER TABLE`) চালানো সম্পূর্ণ নিষিদ্ধ।
