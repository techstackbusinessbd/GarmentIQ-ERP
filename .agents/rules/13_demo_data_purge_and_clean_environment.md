# ডেমো ডেটা অপসারণ ও ক্লিন এনভায়রনমেন্ট নীতি (Demo Data Purge & Clean Environment Policy)

> 🛑 **মূল নীতি**:  
> সিস্টেমে কোনো অপ্রয়োজনীয় স্ট্যাটিক বা ডামি ডেমো ডেটা জঞ্জাল হিসেবে থাকবে না। টেস্টিং বা অনবোর্ডিংয়ের প্রয়োজনে যদি কোনো নমুনা ডেটা প্রবেশ করানোও হয়, তবে তা **১-ক্লিকে সম্পূর্ণ অপসারণ (One-Click Purge)** করার কার্যকর ব্যবস্থা সিস্টেমে থাকা বাধ্যতামূলক।

---

## ১. শূন্য অপ্রয়োজনীয় ডেমো ডেটা (Zero Unnecessary Demo Data)
- ফ্রন্টএন্ড বা ব্যাকএন্ডের কোডবেজে কোনো ফেইক স্ট্যাটিক মক অবজেক্ট বা অপ্রয়োজনীয় ডামি রেকর্ড স্থায়ীভাবে রাখা নিষিদ্ধ।
- কোনো টেস্ট বা ডেমো রেকর্ড ডেটাবেজে যুক্ত করা হলে, তাকে স্পষ্ট আইডেন্টিফায়ার বা ট্রানজ্যাকশনাল ডোমেনের অধীনে রাখতে হবে যাতে সিস্টেমকে এক নিমিষে ফ্রেশ প্রোডাকশন স্টেটে নেওয়া যায়।

---

## ২. ১-ক্লিকে ডেমো ডেটা অপসারণ ব্যবস্থা (One-Click Purge Architecture)

সিস্টেমে ডেমো ডেটা ক্লিন করার জন্য ৩টি সমন্বিত মাধ্যম থাকবে:

### ক. এডমিন ড্যাশবোর্ড UI (১-ক্লিক বাটন):
- **অবস্থান**: `Settings` ➔ `System Maintenance` ➔ `Data Management`।
- **বাটন**: `Purge All Demo Data` (লাল সতর্কতামূলক বাটন)।
- **নিরাপত্তা ও কনফার্মেশন**: বাটন ক্লিক করলে একটি স্পষ্ট মোডাল আসবে:
  > *"Are you sure you want to remove all demo data? This action will permanently wipe sample buyers, orders, inventory records, and production entries. Core system units (PCS, KG) and defect codes will remain untouched."*
  > বাটন: `Yes, Purge Demo Data` | `Cancel`
- **ইউজার ফিডব্যাক**: পার্জ সফল হলে ১ সেকেন্ডের মধ্যে টোস্ট নোটিফিকেশন আসবে:  
  *"Demo data removed successfully. System is clean and ready."*

### খ. ব্যাকএন্ড নিরাপদ সার্ভিস ও এপিআই:
- **এন্ডপয়েন্ট**: `POST /api/v1/system/demo-data/purge`
- **সিকিউরিটি**: শুধুমাত্র `SUPER_ADMIN` রোল এই এপিআই কল করতে পারবে।
- **ট্রানজ্যাকশন নিরাপত্তা (`@Transactional`)**: 
  - ক্যাস্কেডিং রিলেশনাল ডেটা (Buyer ➔ Styles ➔ POs ➔ Cutting Orders ➔ Bundle Cards) সুনির্দিষ্ট ক্রমানুসারে ডিলিট হবে।
  - কোনো অসম্পূর্ণ বা এরর হলে সম্পূর্ণ রোলব্যাক হবে (ACID Compliance)।
  - রেসপন্স টাইম অনুর্ধ্ব ৩০০ মিলিসেকেন্ড হতে হবে।

### গ. ডকার ও সিএলআই স্ক্রিপ্ট (১-ক্লিক স্ক্রিপ্ট):
- ডেভ বা সিআই/সিডি এনভায়রনমেন্টে সরাসরি টার্মিনাল থেকে চালানোর জন্য:
  `scripts/purge-demo-data.sql`
- কমান্ড:  
  `docker compose exec postgres psql -U erp_user -d garments_erp -f /scripts/purge-demo-data.sql`

## ৩. সুরক্ষিত ডেটা বনাম অপসারণযোগ্য ডেমো ডেটা

| ক্যাটাগরি | কোনগুলো সুরক্ষিত থাকবে (Never Purged) | কোনগুলো ১-ক্লিকে মুছে যাবে (Purged) |
| :--- | :--- | :--- |
| **সিস্টেম মাস্টার ডেটা** | স্ট্যান্ডার্ড ইউনিট (PCS, DZN, YDS, KG), পোশাকের ডিফেক্ট কোড, কান্ট্রি কোড, গ্লোবাল কারেন্সি। | ডেমো বায়ার, ডেমো সাপ্লায়ার, ডেমো স্টাইল মাস্টার। |
| **ট্রানজ্যাকশনাল ডেটা** | কোনো আসল অর্ডার মুছে যাবে না। | ডেমো পারচেজ অর্ডার, ডেমো কাটিং বান্ডিল, ডেমো ফেব্রিক রোল ও ইনভেন্টরি এন্ট্রি। |
| **ইউজার ও রোলস** | এডমিন ও সিস্টেম ইউজার অ্যাকাউন্ট অক্ষত থাকবে। | ডেমো টেস্ট ইউজার ও স্যাম্পল হিস্ট্রি। |

## ৪. ফারহানার কিউএ টেস্ট সাইন-অফ (QA Test Gate)
ফারহানা চৌধুরী রিলিজ অডিটে ভেরিফাই করবেন:
- [ ] এডমিন ড্যাশবোর্ড থেকে ১-ক্লিক পার্জ বাটনে ক্লিক করলে সিস্টেমের সমস্ত ডেমো রেকর্ড মুছে যায় কি না?
- [ ] পার্জ করার পর ফ্রন্টএন্ড স্ক্রিনে কোনো ক্র্যাশ বা এরর না দিয়ে সুন্দর নিট ও ক্লিন "Empty State" দেখায় কি না?
- [ ] সিস্টেমের কোর কনফিগারেশন (PCS, KG, ইত্যাদি) অক্ষত রয়েছে কি না?
