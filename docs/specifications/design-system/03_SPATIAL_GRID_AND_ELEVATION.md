## ১. ৪px / ৮px বেসলাইন স্পেসিং স্কেল (Baseline Spacing Grid)

গার্মেন্টস ইআরপির সমস্ত মার্জিন, প্যাডিং এবং কম্পোনেন্ট গ্যাপ ৪px এর গুণিতক হিসেবে সুশৃঙ্খলভাবে নির্ধারিত:

| টোকেন নেম | পিক্সেল (PX) | রেম (REM) | ইউআই ব্যবহারের ক্ষেত্র (Intended Usage) |
| :--- | :--- | :--- | :--- |
| **`space-0.5`** | `2px` | `0.125rem` | মাইক্রো অফসেট, ব্যাজের ভেতরের প্যাডিং |
| **`space-1`** | `4px` | `0.250rem` | আইকন ও টেক্সটের মধ্যকার ফাঁকা জায়গা |
| **`space-1.5`** | `6px` | `0.375rem` | বাটন ভেতরের ভার্টিক্যাল প্যাডিং (কমপ্যাক্ট) |
| **`space-2`** | `8px` | `0.500rem` | স্ট্যান্ডার্ড ফর্ম ইনপুট ভার্টিক্যাল প্যাডিং |
| **`space-2.5`** | `10px` | `0.625rem` | ড্রপডাউন মেনু আইটেমের প্যাডিং |
| **`space-3`** | `12px` | `0.750rem` | বাটন ও ইনপুটের হরিজন্টাল প্যাডিং |
| **`space-4`** | `16px` | `1.000rem` | টেবিল সেলের হরিজন্টাল প্যাডিং, কার্ড কমপ্যাক্ট গ্যাপ |
| **`space-5`** | `20px` | `1.250rem` | স্ট্যান্ডার্ড কার্ডের অভ্যন্তরীণ প্যাডিং |
| **`space-6`** | `24px` | `1.500rem` | পেজের প্রধান সেকশনসমূহের মধ্যকার স্পেস |
| **`space-8`** | `32px` | `2.000rem` | ড্যাশবোর্ড প্রধান উইজেট গ্রিড মার্জিন |
| **`space-10`** | `40px` | `2.500rem` | মোডাল ও ডায়ালগ অভ্যন্তরীণ প্যাডিং |
| **`space-12`** | `48px` | `3.000rem` | বড় পেজ লেভেল সেপারেশন |

## ২. রেসপনসিভ ব্রেকপয়েন্টস ও টাচস্ক্রিন ডিসপ্লে স্কেল (Breakpoints)

গার্মেন্টস ফ্যাক্টরির অফিস কম্পিউটার থেকে শুরু করে কাটিং টেবিলের আল্ট্রা-ওয়াইড মনিটর পর্যন্ত নিরবচ্ছিন্ন রূপ:

| ব্রেকপয়েন্ট | প্রস্থ (Min-Width) | ডিভাইস ও ডোমেন ক্ষেত্র |
| :--- | :--- | :--- |
| **`sm`** | `640px` | ট্যাবলেট পোর্ট্রেট ও বড় মোবাইল স্ক্রিন |
| **`md`** | `768px` | ফ্লোর সুপারভাইজার ট্যাবলেট ডিভাইস (iPad/Android) |
| **`lg`** | `1024px` | ল্যাপটপ ও মার্চেন্ডাইজার স্ট্যান্ডার্ড স্ক্রিন (সাইডবার ডিফল্ট ওপেন) |
| **`xl`** | `1280px` | বড় ডেস্কটপ মনিটর ও এক্সিকিউটিভ ড্যাশবোর্ড |
| **`2xl`** | `1536px` | হাই-রেজোলিউশন ফুল এইচডি ডেস্কটপ (১০৮০p) |
| **`3xl`** | `1920px` | **কাটিং টেবিল টার্মিনাল ও কোয়ালিটি ইনস্পেকশন বিগ ডিসপ্লে** |

## ৪. বর্ডার রেডিয়াস স্কেল (Border Radii Ramp)

| টোকেন | রেডিয়াস (PX / REM) | উপাদান ও ব্যবহারের ক্ষেত্র |
| :--- | :--- | :--- |
| **`rounded-none`** | `0px` | ফ্ল্যাট গ্রিড বর্ডার ও ডিভাইডার |
| **`rounded-xs`** | `2px` (`0.125rem`) | টেবিলের ভিতরের মাইক্রো-ট্যাগ |
| **`rounded-sm`** | `4px` (`0.25rem`) | কোড ব্লক, ছোট ড্রপডাউন অপশন |
| **`rounded-subtle`**| `6px` (`0.375rem`) | ফর্ম ইনপুট, সিলেক্ট বক্স, কমপ্যাক্ট বাটন |
| **`rounded-button`**| `8px` (`0.50rem`) | স্ট্যান্ডার্ড অ্যাকশন বাটন, টুলটিপ |
| **`rounded-card`** | `12px` (`0.75rem`) | **মাস্টার কেপিআই কার্ড, ডেটা টেবিল র্যাপার** |
| **`rounded-modal`**| `16px` (`1.00rem`) | পপআপ মোডাল, কনফার্মেশন ডায়ালগ |
| **`rounded-full`** | `9999px` | স্ট্যাটাস পিলস, ইউজার অ্যাভাটার, নোটিফিকেশন ব্যাজ |

## ৫. এলিভেশন ও শ্যাডো স্কেল (Elevation & Shadows)

| এলিভেশন স্তর | শ্যাডো ক্লাস | সিএসএস শ্যাডো ভ্যালু | উপাদান ব্যবহারের ক্ষেত্র |
| :--- | :--- | :--- | :--- |
| **Level 0 (Flat)** | `shadow-none` | `none` | ক্যানভাস ব্যাকগ্রাউন্ড, ফ্ল্যাট টেবিল সেলস |
| **Level 1 (Subtle)**| `shadow-xs` | `0 1px 2px 0 rgba(0, 0, 0, 0.05)` | **মাস্টার কার্ড, টেবিল কন্টেইনার, বাটন** |
| **Level 2 (Raised)**| `shadow-sm` | `0 1px 3px 0 rgba(0, 0, 0, 0.1), 0 1px 2px -1px rgba(0, 0, 0, 0.1)` | হোভার করা কার্ড, সেকেন্ডারি বাটন হোভার |
| **Level 3 (Overlay)**| `shadow-md` | `0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -2px rgba(0, 0, 0, 0.1)` | থিম সুইচার ড্রপডাউন, অটো-কমপ্লিট পপওভার |
| **Level 4 (Floating)**|`shadow-lg` | `0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -4px rgba(0, 0, 0, 0.1)`| সাইড ড্রয়ার, ফ্লোটিং অ্যাকশন বাটন |
| **Level 5 (Dialog)** | `shadow-2xl` | `0 25px 50px -12px rgba(0, 0, 0, 0.25)` | ক্রোম মোডাল উইন্ডো, বায়ার টেক-প্যাক ভিউয়ার |

## ৬. জেড-ইনডেক্স লেয়ারিং হায়ারার্কি (Z-Index Scale)

```css
--z-base: 0;           /* Content surface / সাধারণ কন্টেন্ট */
--z-sticky: 10;        /* Table sticky headers / টেবিল স্টিকি কলাম */
--z-header: 20;        /* Global Top Navigation Bar / গ্লোবাল হেডার */
--z-sidebar: 30;       /* Collapsible Left Navigation / সাইডবার */
--z-dropdown: 40;      /* Popover & Theme Switcher / ড্রপডাউন মেনু */
--z-backdrop: 50;      /* Modal scrim backdrop / মোডাল ব্যাকড্রপ */
--z-modal: 60;         /* Dialogs & Modal Popups / মোডাল উইন্ডো */
--z-toast: 70;         /* Sonner Toast Notifications / টোস্ট অ্যালার্ট */
--z-tooltip: 80;       /* Absolute tooltips / টুলটিপ */
```
